LA FUSION RESTAURANT WEBSITE

How to run:
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code Live Server.

Files:
- index.html: page content and menu
- style.css: responsive design, layout and animations
- script.js: menu filters, mobile navigation and scroll reveal
- assets/: uploaded reference images

The restaurant address, phone, opening time, ratings and listed prices were entered from the supplied information/images. Confirm details with the restaurant before publishing. Update the hero/gallery image selections in style.css if you have approved restaurant photography.
